# Stop Slop
Eliminate predictable AI writing patterns from prose:
1. Cut filler phrases, buzzwords, and marketing fluff.
2. Direct technical clarity.
3. No emojis.
4. No em dashes (—, --, or spaced hyphens).
5. State facts and actions directly.
