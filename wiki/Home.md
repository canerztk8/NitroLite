# NitroLite wiki

This wiki holds the advanced documentation: how NitroLite works, how to script it, how to build and check it, and
the reference material that does not belong in a quick-start README.

**[Download](https://github.com/canerztk8/NitroLite/releases/latest)** ·
**[README](https://github.com/canerztk8/NitroLite#readme)** ·
**[Open an issue](https://github.com/canerztk8/NitroLite/issues)**

## Pages

### Using NitroLite
- **[Why SmartScreen warns](https://github.com/canerztk8/NitroLite/wiki/Why-SmartScreen-warns)** — what the "Windows protected your PC" prompt
  means and how to check the download yourself.
- **[Compatibility](https://github.com/canerztk8/NitroLite/wiki/Compatibility)** — where each capability answer comes from, the direct-WMI
  fallback, remote model profiles, exporting a hardware report and the NitroSense snapshot diff.
- **[Backup and restore](https://github.com/canerztk8/NitroLite/wiki/Backup-and-Restore)** — what a backup file carries across machines and what
  it deliberately does not.
- **[Reporting a bug](https://github.com/canerztk8/NitroLite/wiki/Reporting-a-Bug)** — the in-app bug reporter, diagnostics bundle and logs.
- **[Command line](https://github.com/canerztk8/NitroLite/wiki/Command-Line)** — maintenance commands and one-shot hardware commands for
  scripts, launchers and macro pads.
- **[Linux (experimental)](https://github.com/canerztk8/NitroLite/wiki/Linux)** — install, the udev rule, the `input` group and what the kernel
  backend supports.
